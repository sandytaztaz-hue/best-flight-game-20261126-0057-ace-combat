SKY FALCON — Ace Combat Run is a dense HD jet-combat campaign for the desktop browser: six sorties across a whole sea war, from a sunset cargo intercept to a final duel with the hidden enemy ace GHOST. Fly from inside the cockpit or from a chase camera, build lock-on and fire missiles, pop flares to break the missiles chasing you, burn the afterburner, and watch enemy jets — and enemy ships — explode. Between sorties the hangar shop sells seven upgrades, the crew talks to you, and three save slots keep your campaign.

Six missions, four named allies plus the hidden ace, lock-on missile combat with flares and afterburner, a hangar shop with seven upgrades, sunset / night / storm / fog weather, a full lit console (radar, altimeter, speed, heading, throttle, weapons, fuel, hull, compass, route), WebAudio engine/lock/explosion sound, and results with a letter grade and a per-mission score breakdown.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: every file the game loads lives under `game/`.

Controls: Arrows/WASD steer · E/Q throttle · SHIFT afterburner · SPACE cannon · F or click fire missile · C flares · V cockpit/chase camera · P pause · M mute · ENTER confirm.
